⚡ AniNews REST API Documentation

Use these REST API endpoints in your Mobile App, Discord/Telegram Bot, Website, or Automation Scripts to fetch news with auto-generated Instagram pictures!

GET
/api/v1/posts

Returns a list of anime news articles, each with its direct generated post image URL, caption, and metadata.

fetch('http://localhost:3000/api/v1/posts?limit=10&handle=@mybrand')
.then(res => res.json())
.then(data => console.log(data.data));
GET
/api/v1/posts/latest/image

Directly returns the actual PNG image (image/png) of the latest breaking anime news post!

<img src="http://localhost:3000/api/v1/posts/latest/image?handle=@mybrand&ratio=4:5" alt="Anime Post" />
GET
/api/v1/posts/:id/image

Directly returns the actual PNG image for any specific article ID.

POST
/api/v1/generate-custom

Send your own custom { title, excerpt, image, handle, badge, ratio } and receive the rendered PNG image directly!
